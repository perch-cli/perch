Perch is for one person moving between logins they already hold — their own
accounts, on their own machine. It creates no accounts and authenticates nobody;
it only chooses between logins you have already made yourself.

## Quota ran out. Keep working.

`perch switch` with nothing after it takes the Account with the most room left,
from the Group you said was interchangeable. It asks nothing, because it is what
you type mid-task.

```
$ perch switch
Switched to overflow@example.com, the most room in Group `work`.
Utilization   5-hour    12%  (as of 4m ago)
              7-day     40%  (as of 4m ago)
```

It lands everywhere at once — every terminal, the editor extension, the desktop
app. Your memory, settings, plugins and project history do not move: they are
yours rather than the Account's.

## Or stop being the one who notices

`perch watcher run` reads how full the Account you are on is, prints what it made
of that, and Switches when it runs low. A loop in one terminal, not a daemon —
nothing to install, and Ctrl-C is safe wherever it lands.

```
$ perch watcher run
Watching you@example.com within Group `work`. Reading how full it is every 2m30s, and Switching within that Scope when its fullest Quota Window reaches 80% — to an Account at 70% or under, and never twice inside 15 minutes. Ctrl-C stops.
2026-08-04T12:00:00Z  waiting   40% used, fullest 5-hour
2026-08-04T12:02:30Z  switched  86% used, fullest 5-hour → overflow@example.com
^C
Stopped.
```

Every decision is printed, including the ones where nothing happens — which are
most of them. Nothing changes underneath you until a Group has been told it may.

## And the rest of it

- `perch status` — who you are and how full, served from cache so it is cheap
  enough for a shell prompt.
- `perch add` — gain an Account by logging in, without disturbing the one you are
  using.
- `perch run <target>` — launch Claude Code as one Account in one terminal,
  leaving the active one alone.
- `perch holdings export` — everything Perch holds, in one encrypted file,
  readable by the standard `age` command.

## Install

Perch is pre-1.0. Every release is real and works, but the command line may still
change between them, and the changelog marks every change that breaks something.
macOS, Linux and Windows. Claude Code has to be installed already, for
Perch to have anything to switch between.

On macOS and Linux:

```sh
curl -fsSL https://perch-cli.github.io/perch/install.sh | sh
```

On Windows:

```powershell
irm https://perch-cli.github.io/perch/install.ps1 | iex
```

With Homebrew:

```sh
brew tap perch-cli/perch
brew install perch
```

With npm:

```sh
npm install -g perch-cli
```

Every release carries checksums and signed build provenance:
[github.com/perch-cli/perch/releases](https://github.com/perch-cli/perch/releases).
The installers verify both. Installing by hand, checking those yourself and
building from source are in
[the install guide](/perch/installing/#by-hand).
