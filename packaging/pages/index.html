Perch

Run Claude Code as whichever Claude account you want, without logging in again.

Perch is pre-1.0. These installers give you the latest release, which is real and works, but the command line may still change between versions.

macOS and Linux

curl -fsSL https://mschieller.github.io/perch/install.sh | sh

Windows

irm https://mschieller.github.io/perch/install.ps1 | iex

Homebrew

brew tap mschieller/perch
brew install perch

npm

npm install -g perch-cli@dev

The dev tag is deliberate — there is no latest until 1.0.

Anything else

Every release carries checksums and signed build provenance: github.com/mschieller/perch/releases. The installers verify both. The source, and what any of this actually does, is at github.com/mschieller/perch.
